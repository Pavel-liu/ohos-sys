# OpenHarmony Ark Runtime (JSVM) bindings

Low-level bindings to the Ark Runtime JSVM (JavaScript Virtual Machine) API on OpenHarmony,
exposed by `libjsvm.so`. Provides APIs for creating and managing JavaScript VM instances,
executing JavaScript code, and interacting with JS values.

Available since API-level 11.

C API reference:

- [JSVM NDK guide](https://docs.openharmony.cn/pages/v5.0/en/application-dev/arkcore/jsvm/jsvm-guidelines.md)
- [`jsvm.h` reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/arkcore/jsvm/capi-jsvm-h.md)
