# OpenHarmony Neural Network Runtime bindings

Low-level bindings to the Neural Network Runtime API on OpenHarmony,
exposed by `libneural_network_core.so`. Provides APIs for neural network model
compilation and inference execution.

Available since API-level 11.

C API reference:

- [Neural Network Runtime NDK guide](https://docs.openharmony.cn/pages/v5.0/en/application-dev/ai/neural-network-runtime/neural-network-runtime-guidelines.md)
- [`neural_network_core.h` reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/reference/apis-ai-kit/capi-neural-network-runtime-h.md)
