# OpenHarmony NotificationKit bindings

Low-level bindings to the NotificationKit (notification management) API on OpenHarmony,
exposed by `libohnotification.so`. Provides APIs for publishing, canceling, and managing notifications.

Available since API-level 13. API-10 through API-12 have no bindings.

C API reference:

- [Notification NDK guide](https://docs.openharmony.cn/pages/v5.0/en/application-dev/notification/notification-ndk-guidelines.md)
- [`notification.h` reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/reference/apis-notification-kit/capi-notification-h.md)
