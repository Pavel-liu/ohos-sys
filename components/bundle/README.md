# OpenHarmony Bundle bindings

Low-level bindings to the Bundle (application bundle management) API on OpenHarmony,
exposed by `libbundle_ndk.z.so`. Provides functions for querying application bundle information,
including application info, ability info, and metadata.

Available since API-level 11.

C API reference:

- [Bundle NDK guide](https://docs.openharmony.cn/pages/v5.0/en/application-dev/arkapi-ndk-bundle.md)
- [`bundle.h` reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/reference/apis-ability-kit/capi-bundle-h.md)
