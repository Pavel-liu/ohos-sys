# OpenHarmony TransientTask bindings

Low-level bindings to the TransientTask (transient task suspension delay) API on OpenHarmony,
exposed by `libtransient_task.z.so`. Provides functions for requesting transient task suspension delays.

Available since API-level 11 (type definitions) and API-level 13 (request APIs).

C API reference:

- [`transient_task_type.h` reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/reference/apis-background-task-kit/capi-transient-task-type-h.md)
- [`transient_task_api.h` reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/reference/apis-background-task-kit/capi-transient-task-api-h.md)
