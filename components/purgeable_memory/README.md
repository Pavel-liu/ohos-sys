# OpenHarmony PurgeableMemory bindings

Low-level bindings to the PurgeableMemory (purgeable/reclaimable memory) API on OpenHarmony,
exposed by `libpurgeable_memory.so`. Provides functions for managing purgeable memory.

Available since API-level 10.

C API reference:

- [`purgeable_memory.h` reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/reference/apis-memory-kit/capi-purgeable-memory-h.md)
