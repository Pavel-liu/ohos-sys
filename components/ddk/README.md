# OpenHarmony DDK bindings

Low-level bindings to the DDK (Driver Development Kit) API on OpenHarmony,
exposed by `libddk.so`. Provides functions for developing peripheral drivers.

Available since API-level 12.

C API reference:

- [`ddk_api.h` reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/reference/apis-driver-kit/capi-ddk-api-h.md)
- [`ddk_types.h` reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/reference/apis-driver-kit/capi-ddk-types-h.md)
