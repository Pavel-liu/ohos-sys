# OpenHarmony BackgroundProcessManager bindings

Low-level bindings to the BackgroundProcessManager API on OpenHarmony,
exposed by `libbackground_process_manager.so`. Provides functions for managing background processes.

Available since API-level 17.

C API reference:

- [`background_process_manager.h` reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/reference/apis-background-task-kit/capi-background-process-manager-h.md)
