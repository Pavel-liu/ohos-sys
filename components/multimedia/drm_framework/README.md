# OpenHarmony DRM Framework bindings

Low-level bindings to the multimedia DRM Framework API on OpenHarmony,
exposed by `libnative_drm.so`. Provides APIs for digital rights management,
including media key session management and DRM module configuration.

Available since API-level 11.

C API reference:

- [DRM NDK guide](https://docs.openharmony.cn/pages/v5.0/en/application-dev/media/drm/drm-guidelines.md)
- [`native_drm.h` reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/reference/apis-media-kit/capi-native-drm-h.md)
