# OpenHarmony Image Effect bindings

Low-level bindings to the multimedia Image Effect API on OpenHarmony,
exposed by `libimage_effect.so`. Provides APIs for applying image filters and effects,
including filter chain construction and effect processing.

Available since API-level 12. API-10 and API-11 have no bindings.

C API reference:

- [Image Effect NDK guide](https://docs.openharmony.cn/pages/v5.0/en/application-dev/media/image-effect/image-effect-guidelines.md)
- [`image_effect.h` reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/reference/apis-media-kit/capi-image-effect-h.md)
