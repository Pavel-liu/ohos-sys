# OpenHarmony USB Serial DDK bindings

Low-level bindings to the USB Serial DDK API on OpenHarmony,
exposed by `libusb_serial.so`. Provides functions for developing USB serial device drivers.

Available since API-level 18.

C API reference:

- [USB Serial DDK reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/reference/apis-driver-kit/capi-usb-serial-ddk-h.md)
