# OpenHarmony NativeEffect bindings

Low-level bindings to the NativeEffect (visual effect filter) API on OpenHarmony,
exposed by `libnative_effect.so`. Provides functions for applying visual effect filters.

Available since API-level 12.

C API reference:

- [`effect_types.h` reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/reference/apis-graphics-kit/capi-effect-types-h.md)
- [`effect_filter.h` reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/reference/apis-graphics-kit/capi-effect-filter-h.md)
