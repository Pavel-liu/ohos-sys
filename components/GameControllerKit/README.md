# OpenHarmony GameControllerKit bindings

Low-level bindings to the GameControllerKit (game controller management) API on OpenHarmony,
exposed by `libohgame_controller.z.so`. Provides APIs for managing game controllers, including
connecting, disconnecting, and reading input from game controllers.

Available since API-level 21. API-10 through API-20 have no bindings.

C API reference:

- [GameControllerKit NDK guide](https://docs.openharmony.cn/pages/v5.0/en/application-dev/game/gamecontrollerkit-guidelines.md)
- [`game_controller.h` reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/reference/apis-game-kit/capi-game-controller-h.md)
