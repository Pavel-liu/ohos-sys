# OpenHarmony HiAppEvent bindings

Low-level bindings to the HiAppEvent (application event logging) API on OpenHarmony,
exposed by `libhiappevent_ndk.z.so`. Provides functions for logging application events,
including writing, configuring, and managing event data.

Available since API-level 12. API-10 and API-11 have no bindings.

C API reference:

- [HiAppEvent NDK guide](https://docs.openharmony.cn/pages/v5.0/en/application-dev/dfx/hiappevent-guidelines-ndk.md)
- [`hiappevent.h` reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/reference/apis-performance-analysis-kit/capi-hiappevent-h.md)
