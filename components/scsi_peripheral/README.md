# OpenHarmony SCSI Peripheral DDK bindings

Low-level bindings to the SCSI Peripheral DDK API on OpenHarmony,
exposed by `libscsi_peripheral.so`. Provides functions for developing SCSI peripheral device drivers.

Available since API-level 18.

C API reference:

- [SCSI Peripheral DDK reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/reference/apis-driver-kit/capi-scsi-peripheral-ddk-h.md)
