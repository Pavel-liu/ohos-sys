# OpenHarmony NativeDisplaySoloist bindings

Low-level bindings to the NativeDisplaySoloist API on OpenHarmony,
exposed by `libnative_display_soloist.so`. Provides functions for display soloist scheduling.

Available since API-level 12.

C API reference:

- [`native_display_soloist.h` reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/reference/apis-graphics-kit/capi-native-display-soloist-h.md)
