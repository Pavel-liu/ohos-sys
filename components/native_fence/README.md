# OpenHarmony NativeFence bindings

Low-level bindings to the NativeFence API on OpenHarmony, exposed by
`libnative_fence.so`. Provides APIs for validating, waiting on, and closing
native fence file descriptors.

Available since API-level 20. API-10 through API-19 have no bindings.

C API reference:

- [`native_fence.h` reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/reference/apis-arkgraphics2d/capi-native-fence-h.md)
