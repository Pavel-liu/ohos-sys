# OpenHarmony NativeColorSpaceManager bindings

Low-level bindings to the NativeColorSpaceManager API on OpenHarmony,
exposed by `libnative_color_space_manager.so`. Provides functions for managing color spaces.

Available since API-level 13.

C API reference:

- [`native_color_space_manager.h` reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/reference/apis-graphics-kit/capi-native-color-space-manager-h.md)
