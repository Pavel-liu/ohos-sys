# OpenHarmony HID DDK bindings

Low-level bindings to the HID DDK (Human Interface Device Driver Development Kit) API on OpenHarmony,
exposed by `libhid_ddk.so`. Provides functions for developing HID device drivers.

Available since API-level 11.

C API reference:

- [`hid_ddk_api.h` reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/reference/apis-driver-kit/capi-hid-ddk-api-h.md)
- [`hid_ddk_types.h` reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/reference/apis-driver-kit/capi-hid-ddk-types-h.md)
