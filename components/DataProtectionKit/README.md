# OpenHarmony DataProtectionKit bindings

Low-level bindings to the DataProtectionKit (DLP permission) API on OpenHarmony,
exposed by `libohdlp_permission.so`. Provides APIs for accessing data loss prevention (DLP) files,
including getting DLP permission info, checking sandbox status, and managing sandbox application configuration.

Available since API-level 14. API-10 through API-13 have no bindings.

C API reference:

- [DataProtectionKit NDK guide](https://docs.openharmony.cn/pages/v5.0/en/application-dev/security/dlp/dlp-ndk-guidelines.md)
- [`dlp_permission_api.h` reference](https://docs.openharmony.cn/pages/v5.0/en/application-dev/reference/apis-data-protection-kit/capi-dlp-permission-api-h.md)
